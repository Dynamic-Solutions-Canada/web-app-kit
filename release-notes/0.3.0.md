- Fixes Back closing the browser tab, or doing nothing, after a dialog declined a Back. In Chrome, pressing Back twice on a dialog that refuses to close (for example while it saves) could close a tab opened from a link, and any dialog closed with Back could make the next Back skip the page. Back on a dialog no longer adds history entries, so Chrome keeps the page in place.
- A "Discard changes?" prompt raised when Back reaches a dialog now works with Back too: Back dismisses the prompt, and the next Back raises it again, as many times as needed.
- Adds `suspended` to `BackAwareModal`: it hides a dialog without closing it, keeping its place in history and its contents' state, for example while a loading screen covers the app. Back still reaches a suspended dialog.
- Adds `useResetOnChange`, which resets a component's state when a prop changes without a stale frame. It is the same hook apps already use, so app copies can switch to the kit's import unchanged.
- Opening a dialog now takes one extra history step. Code that listens to `popstate` sees one more event per dialog, and Forward after a dialog closes does nothing visible.
- Install approval: approve the kit once with `npm install-scripts approve --no-allow-scripts-pin @dynamic-solutions-canada/web-app-kit`, which writes `"github:Dynamic-Solutions-Canada/web-app-kit": true` and covers every later tag. Replace a `@dynamic-solutions-canada/web-app-kit@X.Y.Z` key, which npm never matches for a git dependency, or a `github:...#<commit>` key, which stops matching at the next tag. The kit builds on install either way; the key only clears npm's warning.
- After bumping, re-check Back on a real Android device: a dialog that declines twice in a row with no tap between, and a prompt raised from Back.
