- Adds `BackAwareModal`, a drop-in replacement for Joy's `Modal`: browser and Android Back close the top dialog instead of leaving the page, and a dialog that declines a close (for example to confirm discarding changes) still closes on the next Back.
- Clicks on the scrim no longer close a dialog; set `dismissOnBackdropClick` for surfaces with nothing to lose, such as an image viewer.
- Adds `hasOpenBackAwareDialog`, `hasPendingBackAwareDialog` and `subscribeBackAwareDialogs`, so an app can hold automatic updates or route a native Back button while a dialog is open.
- Adds `isBackGestureClose(event)`, to tell Back apart from the close button in logs.
- Adds an opt-in ESLint config, `@dynamic-solutions-canada/web-app-kit/eslint`, that reports any direct use of Joy's `Modal`.
- Works with React 18.3 or 19, Joy UI 5.0.0-beta.52, ESLint 9 or 10, and Node 22.22.2 or later on the 22 and 24 lines.
- After installing, approve the kit's install script with `npm install-scripts approve @dynamic-solutions-canada/web-app-kit@0.1.0`, and do not install with `--ignore-scripts`, which skips the build.
