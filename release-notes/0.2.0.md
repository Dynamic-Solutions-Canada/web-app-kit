- Adds `EmptyState`, the one surface for a list or page with nothing to show: an icon, a title, one sentence on why or what to do, and an optional action, centred in a dashed card that follows the light and dark themes.
- `title` and `description` accept any content, not only text; the icon is hidden from screen readers.
- Restyle every empty state once from the app's Joy theme through the stable `WebAppKit-EmptyState-*` class names (exported as `emptyStateClasses`), or per use with `sx`. A global CSS rule needs at least two classes to win; see the README.
- No changes to `BackAwareModal`; apps on v0.1.0 can bump without edits. Approve the new version's install script after installing: `npm install-scripts approve @dynamic-solutions-canada/web-app-kit@0.2.0`.
